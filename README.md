# 🚀 Next.js Project

This project is built using **Next.js** and bootstrapped with  
[`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

---

## 📌 Tech Stack

### Frontend
- **Next.js**
- **Shadcn Ui**
- **TypeScript**

### Authentication
- **Clerk**

### Database
- **PostgreSQL**
- **Prisma ORM**

### Media Management
- **ImageKit**

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm / bun
- clone the repo and npm run dev
